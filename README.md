# NEON PLAYER — Native Android Music Player

Полноценный проект музыкального плеера для Android:
- **Архитектура**: MVVM, Clean Architecture, Kotlin Coroutines & Flow
- **Интерфейс**: Jetpack Compose, Material 3, Dark Neon Theme
- **Воспроизведение**: AndroidX Media3 ExoPlayer, MediaSessionService
- **Локальная музыка**: Android MediaStore (MP3, FLAC, WAV, AAC, M4A)
- **Звук**: Android Equalizer API, BassBoost
- **Хранение данных**: Room Database / DataStore

## Сборка APK на GitHub Actions:
1. Загрузите файлы в ваш репозиторий GitHub.
2. В файле `.github/workflows/android.yml` уже настроена автоматическая сборка.
3. Перейдите во вкладку **Actions**, дождитесь зеленой галочки и скачайте готовый APK из раздела **Artifacts**!
